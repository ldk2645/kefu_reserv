# 真正使用前的资料准备

1. 从店铺导出商品列表。将真实 `brand`、`product_name`、`canonical_model` 和 `merchant_sku` 填入你自己的 CSV；不要把营销标题当硬件型号。
2. 按产品型号收集官方说明书 PDF 或官方资料 URL，导入时核实来源，操作员批准后才可用于客户问答。
3. 视频不必下载。人工打开官方教学视频，确认链接可用、确实适用该型号和问题，把 URL 录入视频 CSV 或 UI，设 `verified_status=approved`、`customer_shareable=true`。
4. 若视频属于其他型号、站外内容不明、短链无法确认，保持 pending。
5. 真实材料涉及公司资产、客户资料时依组织许可和数据保护要求管理，不要把真实客户信息写进公共 Git 仓库。

**注意**：样例 `DEMO-*` 和 `example.com` 都是虚构测试数据，不得作为真实官方来源发送给买家。
