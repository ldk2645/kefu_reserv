# 07｜统一决策记录：用于解决此前聊天各版要求冲突

此文件为**最终有效规则**，替代原来发给 Codex 的零散修改消息。

| 争议/历史想法 | 最终决定 | 说明 |
|---|---|---|
| 预训练/微调 | **不做** | RAG + Prompt 更符合小范围高频产品快速迭代 |
| 视频自动提取音频字幕/关键帧 | **取消** | 视频量大，当前只需要视频 URL 供客户使用 |
| 官方视频链接是否能发 | **允许已核实正确的官方链接直接加入待审核回复** | 用户确认业务上可发送，不要求上传视频文件 |
| 所有外链一律禁止 | **不采用** | 针对已核实官方教程，允许；仍由人最终审核实际平台适用性 |
| 说明书自动爬取 | **P1/M4 半自动官方采集** | P0 首先支持手动上传和检索；不为爬虫阻塞 MVP |
| 知识来源 | **官方说明书优先，官方 FAQ 辅助** | 退款物流另以有效店铺 SOP 和平台规定为准 |
| 全自动发消息 | **V0.1 不做** | 只审核复制，用户手动粘贴发送；以后如获授权再考虑 |
| 屏幕读取方式 | **用户主动截取选区 + 本地 OCR** | 自动监听仅在后续授权评估后开发 |
| 桌宠“大肥鱼”样式 | **仅借鉴机灵、略嘴硬但可靠的性格** | 原创“小鲸”占位，不照搬素材/代码；只对操作员说话 |
| 客户侧风格 | **专业、简短、亲和、自然** | 对客户绝对不能输出桌宠吐槽/吃 token 等内容 |
| API 选择 | **可配置的 OpenAI 兼容接口** | 不绑定尚未核实存在的某模型版本，无 Key 可 demo |
| 索引方案 | **先轻量检索，后向量化** | 中文检索先用简单可解释检索和型号过滤 |
| 商品清单 | **优先 SKU/型号 Excel 或 CSV** | P1 批量导入；P0 可在 UI 手动维护单个型号 |
| 真实订单状态 | **无官方授权接入不查询** | 不得谎称查看订单或承诺送达时刻 |

## 一句话产品定义

> 在获得允许的客服画面中，通过手动截屏和本地 OCR 读取客户问题，用**经过审核、精确型号匹配的官方说明书**形成答案；根据场景可直接附上**已经核实的官方教程视频 URL**；采用轻量、自然的客户客服话术，操作员逐条审核并复制，不自动发送。
