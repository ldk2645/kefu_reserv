# 06｜Windows 部署、数据安全和日常维护

## 1. 预期启动命令（由 Codex 实际代码落实）

```powershell
cd pdd-visual-copilot
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m app.main
```

测试：

```powershell
pytest -q
```

如果 Windows PowerShell 拦截虚拟环境激活，应在 README 提供**不修改系统全局执行策略**的替代方式，如直接使用 `.venv\Scripts\python.exe` 运行。不要把修改安全策略作为唯一选择。

## 2. 模型配置

根目录 `.env` 应从 `.env.example` 手动复制，填写用户自己有权使用的 API。配置变量举例：

```text
AI_ENABLED=false
AI_BASE_URL=
AI_API_KEY=
AI_MODEL=
AI_TIMEOUT_SECONDS=25
```

API Endpoint/模型实际可用性取决于所用服务商；**不预设 DeepSeek 某个特定未核实版本一定存在**。若配置为空或开关关闭，只使用 MockProvider，界面清晰写明“演示模式”。密钥不写入日志、测试文件、截图或 Git。

## 3. 隐私与组织合规

- 只截用户已获授权查看的 PDD 聊天区域；默认手动触发、不后台持续监控、不读取无关屏幕内容。
- 截图在本地内存中 OCR，默认不存盘、不上传第三方。
- 外部 LLM 默认关闭；用户主动启用并确认使用前，应遵守公司允许的业务数据处理政策。
- 传输前脱敏手机号、详细地址、订单号、姓名等尽量可识别字段，提供预览；正则不能完全识别隐私，因此**人工预览仍必要**。
- 上传内容只含必要客户问题、确认为相关的上下文、检索知识短片段；不传完整订单记录、原始截图。
- 控制日志只存耗时、错误类别、资料 ID、匿名统计，不落盘聊天原文和密钥；私有素材保存在本地非 Git 目录。
- 聊天中包含恶意 prompt 注入时，视为普通非可信数据；软件不得按客户命令执行系统动作。
- 官网说明书采集须遵循网站授权和访问政策，不绕过认证、验证码、速率限制。

## 4. 资料更新维护

- 每增一个商品：导入 SKU/型号 → 上传官方说明书（或使用经审核的官方发现模块）→ 人工核对 → approved → 可使用。
- 每增一个视频：录入官方链接 → 打开确认视频确属对应型号/问题 → 标 approved 与 customer_shareable → 才允许生成建议链接。
- 某型号出了新版：新建知识版本，经人工审核后 deprecated 老版；不要静默覆盖旧版。
- 处理过的投诉和事故：可以沉淀匿名 FAQ，但官方产品事实与店铺政策必须独立保存。

## 5. 上线前人工审查

首次投入实际店铺前，检查业务负责人是否批准使用外部 AI、是否需要数据处理协议，确认客服站内可发送的官方视频链接形式，确认本机安全软件允许截图/OCR/剪贴板，使用测试会话完成流程。第一版不提供真实自动发送；任何想增加自动操作 PDD 客户端的需求要先做单独权限和可靠性评估。

## 6. 常见故障预案

| 问题 | 回退 |
|---|---|
| OCR 把左右气泡混淆 | 人工编辑最新买家问题，重新生成 |
| 官方说明书没有该型号 | 禁止使用类似型号，手动导入/追问 |
| API 没余额/超时 | 切回 mock（仅测试）或使用手动保守回复，不能把 mock 当真实资料 |
| 视频无法打开 | 从客户回复删除 URL，改为描述说明书中已核实步骤 |
| PDF 图示较多 | 显示原文页码，提示人工打开原图核对 |
| 软件多屏位置偏移 | 重选截图区域，记录屏幕缩放比以便修复 |
